# Current manuscript: Operations Research Forum

**Accuracy-Aware Row Scaling for Generated Mixed-Integer Programs: A Computational
and Software Study**, by Mathias Rodríguez Castro.

Run `make paper` from the repository root. Current documents are
`orf/main_orf.pdf`, `orf/ESM_1.pdf` (Online Resource 1), and `orf/cover-letter.pdf`.
[ORF sources and build](orf/README.md) describe the canonical editorial fragments;
[submission preparation](submission/orf/README.md) describes the complete delivery.
The journal's publisher class/style and download provenance are in `orf/`.

The adaptation changes framing, contribution order, practical interpretation,
format, declarations and resource names. Scientific statements, proofs, experiment
records, numerical tables and adverse evidence remain intact. The inherited
scientific ZIP is exactly the independently checked OMS v1.3.17 archive.

`main.tex`, `supporting-information.tex`, `sections/`, `tables/` and
`research-references.bib` preserve the shared scientific source and the preceding
OMS presentation. The current ORF copies are generated by
`scripts/research/build_orf.py`; the self-contained editable ZIP contains complete
TeX sources for direct compilation. The old OMS workflow is documented in
[the preserved preparation notes](submission/oms/README.md). Its frozen PDFs and
archives remain in the local versioned release directory.

Use `make orf-package`, `make orf-validate` and
`python3 scripts/research/freeze_orf.py` for the current delivery. Verification
checks clean source builds, the unchanged scientific archive, mathematical/text
preservation and table/figure regeneration. The code/data ZIP is Online Resource 2.
The author has deferred its new Zenodo DOI until final submission preparation.
Authorship, funding, competing interests and assistive-tool documentation remain
explicit. Manuscript text and PDFs are outside the code/data licenses.
